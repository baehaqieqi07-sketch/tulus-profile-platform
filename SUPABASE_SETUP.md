# Supabase Setup

1. Buat project Supabase.
2. Copy URL dan anon key ke `.env`.
3. Jalankan `supabase/schema.sql`.
4. Jalankan `supabase/rls-policies.sql`.
5. Jalankan `supabase/storage-policies.sql`.
6. Buat bucket `profile-media`, `payment-proofs`, dan `brand-assets`.
7. Jangan pernah taruh service role key di frontend.

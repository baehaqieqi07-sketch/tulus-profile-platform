# TULUS Major Platform Update

Update ini mengubah UI utama menjadi sistem premium bio platform yang lebih jelas dan konsisten.

Fokus:
- Landing dibuat ulang dengan hero besar, profile preview, social brand strip, flow, fitur, dan CTA jelas.
- Public profile dibuat ulang jadi fullscreen bio-style dengan click-to-enter, avatar, badge, social icon, music, views, dan quote.
- Dashboard shell dibuat ulang menjadi creator workspace yang lebih rapi.
- Customize dan Links Studio dibuat ulang supaya alur edit jelas.
- Help Center dibuat lebih rapi dengan search, category grid, FAQ, dan AI bekiw panel.
- Game Center dibuat lebih playable dengan score, best, combo, lives, level, timer, dan streak.
- CSS final `src/styles/tulus-major-platform.css` diimport terakhir supaya tidak kalah oleh CSS lama.

Catatan:
- Tidak copy asset/nama/layout persis dari website lain.
- Brand publik tetap TULUS.
- Supabase, login, route, data lama tetap dipertahankan.
